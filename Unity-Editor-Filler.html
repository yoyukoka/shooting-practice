🖥️

Unityの画面を見てみよう

まずは5つのウィンドウを覚えましょう

Scene (シーン)

📐

ゲームの設計図

✏️ オブジェクトを配置・編集する場所

🎨 ゲームの見た目を作り込む画面

🔍 拡大・縮小・回転して色々な角度から見られる

用語：Scene（シーン）= ゲームの1画面のこと。タイトル画面、ゲーム画面などを分けて作る

Game (ゲーム)

🎮

実際にプレイする画面

▶️ 再生ボタンを押すとここでゲームが動く

👀 プレイヤーが実際に見る画面そのまま

🎥 カメラの視点で表示される

豆知識：Sceneは作業画面、Gameは完成品プレビュー！

Hierarchy (ヒエラルキー)

📋

シーン内のオブジェクト一覧

📦 シーンに配置された全てのオブジェクトが表示される

🌳 親子関係（階層構造）で整理できる

👆 クリックすると、そのオブジェクトを選択できる

用語：Hierarchy（階層）= ものの並び順や親子関係のこと

Inspector (インスペクター)

🔧

オブジェクトの詳細設定画面

⚙️ 選択中のオブジェクトの設定を表示・編集

📊 位置、大きさ、色など全ての設定がここに

🔌 Component（機能パーツ）を追加・削除できる

用語：Inspector（検査官）= オブジェクトの中身を詳しく見る・いじる場所

Project (プロジェクト)

📁

プロジェクト内の全ファイル管理

🗂️ 画像、音声、スクリプトなど全ての素材がここに

📂 フォルダで整理できる（Windowsのエクスプローラーみたいなもの）

🎨 ここから素材をシーンにドラッグ&ドロップして使う

📦 GameObjectとComponent

📦

GameObject

ゲーム内の「モノ」

プレイヤー、敵、カメラなど
全てがGameObject

空の箱のようなもの。機能を持たせるにはComponentを追加する

🔧

Component

機能を追加するパーツ

見た目、物理、スクリプトなど
機能を組み合わせる

例：SpriteRenderer（見た目）、Rigidbody2D（物理）、自作スクリプト（動き）

➕ Componentの追加・削除

Inspectorでの基本操作

  1. 1. Hierarchyでオブジェクトを選択する
  2. 2. Inspector下部の Add Component をクリック
  3. 3. 検索欄に名前を入力（例：Rigidbody 2D）
  4. 4. 一覧から選んで追加

🗑️ 不要なComponentは、右上の ︙ メニュー → Remove Component で削除

スクリプトは Project からオブジェクトへドラッグ&ドロップでもアタッチできる

💥 衝突判定に必要なもの

🔲⚛️

🔲 Collider2D で当たり判定の形を作る

⚛️ Rigidbody2D で物理演算を有効化

🏷️ Tag で隕石かどうか判定（Inspectorで設定）

💡 衝突を検出するには、Collider2DとRigidbody2Dの両方が必要なことが多い

🔲 Collider2Dとは？

当たり判定の形を定義するComponent

⬜

BoxCollider2D

四角形

⭕

CircleCollider2D

円形

🔷

PolygonCollider2D

複雑な形

💡 今回はBoxCollider2D（プレイヤー）とCircleCollider2D（隕石）を使います

Sceneビューで緑の枠線が当たり判定の範囲。Edit Colliderで形を調整できる

⚛️ Rigidbody2Dとは？

物理演算を有効化するComponent

🌍 重力の影響を受けるようになる

💥 衝突判定が機能するようになる

🎯 物理的な動きをシミュレーション

⚠️ 重要な設定

Gravity Scale を 0 にする！

（重力で下に落ちないようにするため）

💡 衝突判定には少なくとも片方にRigidbody2Dが必要

🎯 Trigger（Is Trigger）とは？

すり抜ける当たり判定

通常のCollider

物理的にぶつかる

壁に当たって止まる感じ

Is Trigger ON

すり抜けて検出だけする

センサーのような感じ

💡 Collider2Dの Inspector で Is Trigger にチェックを入れるとTriggerになる

弾など「当たったことだけ検知したい」ときに使う

🏷️ Tagとは？

オブジェクトにラベルを付ける機能

🏷️ 「これは敵」「これはアイテム」と識別できる

🔍 スクリプトからタグで検索・判定できる

📝 今回は隕石に"Falling"タグを付ける

CompareTag() を使うと高速かつ安全に判定できる

タグの設定方法（Inspector）

1. 隕石を選択

2. Inspector上部の Tag → 「Add Tag...」

3. 「Falling」を新規追加

4. 隕石を再選択 → Tag で「Falling」を選ぶ

💡 使う前に必ずタグを「追加 → 割り当て」まで行う

🔧 Componentの設定

忘れずに設定しよう！

Playerの設定

  • ✅ Rigidbody2Dを追加
  • ✅ Gravity Scale → 0
  • ✅ BoxCollider2Dを追加

隕石の設定

  • ✅ Tag → Falling
  • ✅ Rigidbody2Dを追加
  • ✅ Gravity Scale → 0
  • ✅ CircleCollider2Dを追加

Hierarchyで選ぶ → Inspectorで設定、の流れを慣れよう

📋 Prefabとは？

GameObjectの「設計図」

🌑 → 📋 → 🌑🌑🌑🌑🌑

📝 1つ作れば、同じものを何個でも作れる

✏️ Prefabを編集すると、全部に反映される

💾 再利用できるテンプレートとして保存

Prefabの作り方（エディタ操作）

  1. 1. Hierarchyの隕石を選択
  2. 2. Projectウィンドウにドラッグ&ドロップ
  3. 3. 📋マークがついたらPrefab完成！
  4. 4. Projectからシーンへドラッグで複製配置

📺 Canvasとは？

UI（ユーザーインターフェース）を表示する場所

🖼️ 画面上にテキストやボタンを配置するための土台

📱 画面サイズが変わっても自動で調整される

🎨 スコア、HP、メニューなど全てのUIをここに配置

Canvasの作り方

  1. 1. Hierarchy右クリック → UI → Canvas
  2. 2. Canvas Scalerを設定（画面サイズに合わせて自動調整）

UI = User Interface（ユーザーが見る画面の情報）

📝 TextMeshProとは？

画面に文字を表示するUIコンポーネント

✍️ スコア、タイマー、メッセージなどを表示

🎨 フォント、サイズ、色を自由に変更できる

📍 画面の好きな位置に配置できる

Textの作り方

  1. 1. Canvas右クリック → UI → Text - TextMeshPro
  2. 2. 初回は「Import TMP Essentials」をクリック
  3. 3. Inspectorで位置、サイズ、色を調整
