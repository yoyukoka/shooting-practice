⌨️ Input.GetKey()とは？

キーが押されている間、true を返す

if (Input.GetKey(KeyCode.A)) { // Aキーが押されている間、ずっと実行 }

上の例は左移動（Aキー）の書き方

右移動では、対になるキーや矢印キーの KeyCode を使う

📍 移動の書き方

transform.position += new Vector3(-1, 0, 0) * moveSpeed * Time.deltaTime; // 左：x = -1

右方向へ動かすとき、x の値はどうなる？

Time.deltaTime をかけると、PCの性能に関係なく一定速度で動く

💥 OnCollisionEnter2D

ぶつかった瞬間に自動で呼ばれる関数

void OnCollisionEnter2D(Collision2D collision) { if (collision.gameObject.CompareTag("Falling")) { // ここに処理を書く } }

🔧 Componentの設定

コードだけでは当たり判定は動きません！Inspector も確認

Player

  • ✅ Rigidbody2D（Gravity Scale = 0）
  • ✅ BoxCollider2D

隕石

  • ✅ Tag → Falling
  • ✅ Rigidbody2D（Gravity Scale = 0）
  • ✅ CircleCollider2D

📴 SetActive(false) とは？

SetActive(false)
